# ordinacebakalare.cz

Prozatímní statický web Ordinace Bakaláře s.r.o., hostovaný na GitHub Pages.

## Struktura

- `index.html` – celá stránka (bez externích závislostí)
- `docs/` – PDF dokumenty (vnitřní řád, ceník, zpracování osobních údajů)
- `CNAME` – vlastní doména pro GitHub Pages

## Úpravy

Ordinační hodiny, telefony i oznámení se mění přímo v `index.html`.
Po commitu do větve `main` se web během minuty aktualizuje.
